Drop your installation photos here (.jpg, .jpeg, .png, .webp).

The gallery page (`/gallery`) automatically picks up every image in this
folder - no code changes needed. Just copy files in.

Tips:
- Landscape photos look best (the grid crops to a consistent shape).
- Keep individual files under a few MB each - large photos slow the page
  down. Resize/compress before adding if your camera exports very large files.
- No caption is shown on the page - the filename is never displayed to visitors,
  only used internally (as invisible accessibility/SEO text). Rename to
  anything you like, or leave auto-generated names (e.g. from pasting) as is.
- Before adding a photo, check it for: identifiable faces (get the person's
  OK first) and location watermarks showing an exact address/GPS coordinates
  (crop those out - there's no upside to publishing a customer's exact home
  address, only risk).
